# Aranya-AI: Medicinal Botanical Identification

## The Vision
The North Eastern Region harbors immense biodiversity, yet tracking and protecting valuable medicinal flora remains a profound challenge. Aranya-AI bridges traditional ecological knowledge with modern computation.

## The Prototype
We are forging a computer vision pipeline designed to identify medicinal plants from field images. This digital tool aims to assist forest officials, local communities, and conservationists in rapid botanical verification.

## Technical Architecture
* **Frontend:** Streamlit for a seamless, interactive user experience.
* **Backend:** Python acting as the operational core.
* **Computer Vision:** Pre-trained Convolutional Neural Networks (CNN) for image classification and feature extraction.
* **Workspace:** VS Code.
